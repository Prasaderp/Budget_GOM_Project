# Prompt System

Simple, powerful prompts for AGI-level software development.

## Structure
```
prompts/
├── 01-system.md      # Core AI behavior (always load)
├── 02-think.md       # Human thinking process
├── 03-implement.md   # Implementation rules
├── 04-checklist.md   # Quick reference checks
```

## Usage
Reference `@prompts` folder in chat with your task. The prompts guide AI to think like a senior developer.

## Files
| File | Purpose | When |
|------|---------|------|
| `01-system.md` | Core identity & rules | Always |
| `02-think.md` | How to analyze before coding | New features, complex tasks |
| `03-implement.md` | How to write code | All coding tasks |
| `04-checklist.md` | Quick validation checks | Before/after code |
