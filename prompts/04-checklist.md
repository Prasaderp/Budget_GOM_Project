# Quick Checklist

Fast validation at each stage.

## Before Coding
```
□ Understood requirement?
□ Searched for existing code?
□ Know where code goes?
□ Listed edge cases?
```

## During Coding
```
□ Following existing patterns?
□ Functions under 20 lines?
□ Errors handled?
□ Inputs validated?
```

## After Coding
```
□ Works as expected?
□ Edge cases covered?
□ No code duplication?
□ Self-documenting names?
```

## Edge Cases (Always Consider)
```
□ Null/empty inputs?
□ Invalid types?
□ Boundary values (0, max)?
□ Network/DB failures?
□ Permission denied?
□ Concurrent access?
```

## Performance (When Relevant)
```
□ N+1 queries?
□ Unbounded results?
□ Missing indexes?
□ Memory for large data?
```

## Security (When Relevant)
```
□ Input sanitized?
□ Auth/authz checked?
□ No secrets in code?
□ Errors don't leak info?
```

## Final Gate
```
□ Simplest solution?
□ Proud of this code?
□ Would pass code review?
```
